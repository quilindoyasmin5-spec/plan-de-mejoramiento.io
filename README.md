# Huellitas del Cauca — Portal de donaciones

Sitio web estático creado con HTML, CSS y JavaScript. Permite consultar las necesidades del refugio y registrar, filtrar, cancelar o eliminar donaciones.

## Archivos
- `index.html`: estructura de la página.
- `style.css`: estilos y diseño adaptable.
- `app.js`: validaciones, filtros y gestión de donaciones.

## Cómo ejecutarlo
Abre `index.html` en el navegador. Bootstrap se carga desde CDN, por lo que se necesita conexión a internet para sus estilos.

Los registros se guardan en el almacenamiento local del navegador (`localStorage`); por eso no se comparten entre distintos dispositivos o navegadores.

## Publicar con GitHub Pages
En el repositorio, entra a **Settings → Pages**. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/(root)`, y guarda. La página quedará publicada en:
https://quilindoyasmin5-spec.github.io/plan-de-mejoramiento.io/
